# AWG 3.0 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in AmneziaWG 3.0 protocol support (HeaderProtectionKey, ContentPaddingAddition, randomized timers) to the docker-amneziawg image while keeping AWG 2.0 (default) and 1.5 behavior unchanged.

**Architecture:** Build `amneziawg-tools` from the first official release that includes upstream PR #60 (native AWG 3.0 config parsing; no branch pins, no runtime workarounds). Extend the s6 init config generator with an `AWG_VERSION=3.0` mode that randomizes all new parameters (ranges aligned with AmneziaWG-Architect "medium" intensity), persists them like existing params, and appends them programmatically to server/peer confs so user templates stay untouched.

**Tech Stack:** Dockerfile (multi-stage, Alpine), bash (s6-overlay init scripts), GitHub Actions, Docker for verification.

**Spec:** `docs/superpowers/specs/2026-07-26-awg-3.0-support-design.md`

**Branch:** `feat/awg3-support` — all commits go there; PR to `master` at the end.

**Prerequisite:** an official amneziawg-tools release newer than `v1.0.20260618-2` that includes PR #60 ("feat: AmneziaWG 3.0"). Do not start Task 1 before it exists. Check with: `gh release list --repo amnezia-vpn/amneziawg-tools --limit 3`

## Global Constraints

- `AWG_VERSION` default stays `2.0`; `1.5` and `2.0` generation paths must remain byte-identical in behavior.
- amneziawg-go stays pinned at `v3.0.1` (`ARG AMNEZIAWG_GO_VERSION=v3.0.1` — already in Dockerfile, do not change).
- amneziawg-tools is bumped to the first official release that includes PR #60 (AWG 3.0 config parsing); the clone line stays `git clone --branch ${AMNEZIAWG_TOOLS_VERSION} --depth 1 ...`. No branch pins, no CI workflow changes.
- New 3.0 config keys, exact spelling (CamelCase, `[Interface]` section): `HeaderProtectionKey`, `ContentPaddingAddition`, `RekeyAfterTime`, `RekeyTimeout`, `RejectAfterTime`, `KeepaliveTimeout`, `MaxHandshakeAttempts`.
- In 3.0 mode all of S1–S4 must be ≥ 12 (amneziawg-go rejects the config otherwise); S4 must stay ≤ 32.
- Timer invariants: `RejectAfterTime.lo > KeepaliveTimeout.lo + RekeyTimeout.lo` and `RekeyAfterTime.hi < RejectAfterTime.lo`.
- Templates `root/defaults/server.conf` and `root/defaults/peer.conf` must NOT be modified (existing user templates in `/config/templates` keep working).
- **Datapath:** the 3.0 feature set exists only in `amneziawg-go` (userspace). `init-amneziawg-module/run` picks the kernel datapath whenever `ip link add … type wireguard` succeeds (true on most modern hosts — mainline wireguard ≥ 5.6), and there is no override to force userspace. On a kernel-datapath host the 3.0 keys go to a module that cannot apply them, so `AWG_VERSION=3.0` requires userspace mode. Every 3.0 tunnel test MUST first confirm the log line `**** No kernel module available, using userspace amneziawg-go ****`; if it is absent, block/unload the host wireguard module (or run on a host without one) before trusting the result. This is a docs + test-procedure change only — do NOT add code to force userspace in this plan.
- Follow existing code style in `root/etc/s6-overlay/s6-rc.d/init-amneziawg-confs/run`: `AWG_*` env vars with `${VAR:-default}` fallback, `shuf -i lo-hi -n 1` randomization, `**** ... ****` log banners.
- The spec and plan (`docs/superpowers/`) ARE committed on the feature branch (user request) so the work can be resumed from any checkout.

- [ ] **Step 1: Add range helpers and the 3.0 generator function**

In `root/etc/s6-overlay/s6-rc.d/init-amneziawg-confs/run`, immediately AFTER the `generate_default_signatures` function (ends around line 65), insert:

```bash
# Extract lower/upper bound of an "lo-hi" range (single value => lo=hi)
range_lo() { echo "${1%%-*}"; }
range_hi() { echo "${1##*-}"; }

# AWG 3.0: header protection key, content padding, randomized timers.
# Ranges follow AmneziaWG-Architect "medium" intensity. Timer semantics:
# amneziawg-go device/timers.go — each side uses its own values.
generate_awg3_params() {
    # Shared symmetric key — must be identical on server and all clients.
    # Use genpsk (full-entropy 32 random bytes, like PresharedKey), NOT genkey
    # (genkey emits a bit-clamped Curve25519 private key — wrong generator for
    # a symmetric ChaCha20 header-protection key).
    AWG_HEADER_PROTECTION_KEY=${AWG_HEADER_PROTECTION_KEY:-$(awg genpsk)}

    # Extra random zero-padding appended to each transport packet
    if [[ -z "${AWG_CONTENT_PADDING}" ]]; then
        local _lo=$(shuf -i 16-72 -n 1)
        AWG_CONTENT_PADDING="${_lo}-$(shuf -i $((_lo + 8))-128 -n 1)"
    fi
    if [[ -z "${AWG_REKEY_TIMEOUT}" ]]; then
        local _lo=$(shuf -i 4-6 -n 1)
        AWG_REKEY_TIMEOUT="${_lo}-$((_lo + $(shuf -i 1-4 -n 1)))"
    fi
    if [[ -z "${AWG_KEEPALIVE_TIMEOUT}" ]]; then
        local _lo=$(shuf -i 8-14 -n 1)
        AWG_KEEPALIVE_TIMEOUT="${_lo}-$((_lo + $(shuf -i 2-8 -n 1)))"
    fi
    if [[ -z "${AWG_REKEY_AFTER_TIME}" ]]; then
        local _lo=$(shuf -i 100-120 -n 1)
        AWG_REKEY_AFTER_TIME="${_lo}-$((_lo + $(shuf -i 10-25 -n 1)))"
    fi
    if [[ -z "${AWG_REJECT_AFTER_TIME}" ]]; then
        # Must satisfy RejectAfterTime.lo > RekeyAfterTime.hi and
        # RejectAfterTime.lo > KeepaliveTimeout.lo + RekeyTimeout.lo
        local _floor=$(( $(range_hi "${AWG_REKEY_AFTER_TIME}") + $(range_hi "${AWG_KEEPALIVE_TIMEOUT}") + $(range_hi "${AWG_REKEY_TIMEOUT}") + 15 ))
        local _lo=$(( _floor > 170 ? _floor : 170 ))
        AWG_REJECT_AFTER_TIME="${_lo}-$((_lo + $(shuf -i 10-25 -n 1)))"
    fi
    if [[ -z "${AWG_MAX_HANDSHAKE_ATTEMPTS}" ]]; then
        local _lo=$(shuf -i 12-18 -n 1)
        AWG_MAX_HANDSHAKE_ATTEMPTS="${_lo}-$((_lo + $(shuf -i 2-10 -n 1)))"
    fi
}
```

# Append AWG 3.0 params to the server conf (called before any [Peer] section exists)
append_awg3_params() {
    local conf_file=$1
    [[ "${AWG_VERSION}" != "3.0" ]] && return 0
    cat >> "$conf_file" <<EOF
HeaderProtectionKey = ${AWG_HEADER_PROTECTION_KEY}
ContentPaddingAddition = ${AWG_CONTENT_PADDING}
RekeyAfterTime = ${AWG_REKEY_AFTER_TIME}
RekeyTimeout = ${AWG_REKEY_TIMEOUT}
RejectAfterTime = ${AWG_REJECT_AFTER_TIME}
KeepaliveTimeout = ${AWG_KEEPALIVE_TIMEOUT}
MaxHandshakeAttempts = ${AWG_MAX_HANDSHAKE_ATTEMPTS}
EOF
}

# Insert AWG 3.0 params into the [Interface] section of a peer conf (before the [Peer] line)
append_awg3_params_to_interface() {
    local conf_file=$1
    [[ "${AWG_VERSION}" != "3.0" ]] && return 0
    local sig_block="HeaderProtectionKey = ${AWG_HEADER_PROTECTION_KEY}"$'\n'
    sig_block+="ContentPaddingAddition = ${AWG_CONTENT_PADDING}"$'\n'
